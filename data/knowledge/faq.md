# よくある質問（FAQ）

## セキュリティについて
- データは国内データセンターに保存されます
- 通信はTLS 1.3で暗号化
- SOC2 Type II 認証取得済み
- 二要素認証（2FA）対応

## 解約について
- いつでも解約可能（最低利用期間なし）
- 解約後30日間データのエクスポートが可能
- 日割り返金は行いません

## サポート対応時間
- スタンダード: 平日 9:00-18:00
- プロフェッショナル: 平日 9:00-21:00
- エンタープライズ: 24時間365日（重大障害）

## 既存ツールとの連携
- Slack, Microsoft Teams 連携対応
- Salesforce, HubSpot CRM連携（プロプラン以上）
- REST API / Webhook 提供

## 音声・会議データの取り扱い
- 会議の文字起こしデータは暗号化して保存
- 第三者への提供は行いません
- データ保持期間はプランにより90日〜無期限
