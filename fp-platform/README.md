# FP Platform

ファイナンシャルプランナー（FP）専用の非公開ワークスペースです。顧客には表示されない機微情報の入力・面談設計を行います。顧客向けの完成品投影は後続フェーズで実装予定です。

## 起動方法

```bash
cd fp-platform
npm install
npm run dev
```

http://localhost:3000/fp/login を開いてください。

## デモログイン

- メール: `fp@demo.local`
- パスワード: `demo1234`

## FP専用機能（顧客非表示）

| 画面 | 内容 |
|---|---|
| ダッシュボード | 担当顧客数・進行中面談の概要 |
| 顧客一覧 / 登録 | 氏名・連絡先・年収など機微情報 |
| 面談ワークスペース | プロファイル / CF明細 / 資産負債 / 保障 / FPメモ |
| **音声・テキスト自動入力** | 録音・読み上げ・動画/音声ファイル → 文字起こし → 項目自動抽出 |

### 自動入力の使い方

**リアルタイム（面談中）**
1. **ライブ録音** … ブラウザの音声認識で文字起こし（Chrome推奨）
2. **解析して項目を抽出（ルール）** … APIキー不要

**まとめて処理（面談後）— OPENAI_API_KEY 不要**
1. **Cursorまとめて解析** タブを開く
2. 文字起こし全文を貼り付け → **Cursor用プロンプトをコピー**
3. Cursor チャット（月額プラン内）に貼り付けて解析
4. 返ってきた JSON を貼り付け → **JSONを読み込む** → フォームに反映

**ファイル文字起こし（任意）**
- **動画・音声ファイル** … `OPENAI_API_KEY` 設定時のみ Whisper で文字起こし

環境変数（任意・リアルタイム高精度やファイル用のみ）:

```bash
OPENAI_API_KEY=sk-...   # ファイル文字起こし・高精度抽出用
OPENAI_MODEL=gpt-4o-mini
```

## アーキテクチャ方針

- `/fp/*` ルートは FP 専用（ミドルウェアで保護）
- データは `.data/db.json` に保存（MVP）
- 各データ項目は将来の顧客投影用に `classification`（public / summary / confidential）を想定
