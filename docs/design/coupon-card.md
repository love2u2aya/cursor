# クーポンカード UI デザインリファレンス

フードデリバリー／EC系アプリでよく見られる、チケット型クーポンカードのデザインパターン。今後の画面実装・コンポーネント設計の参考用。

## 概要

- **用途:** 利用可能なクーポン一覧の表示
- **メタファー:** 紙の割引券・チケット（左が本体、右が切り取り線付きスタブ）
- **トーン:** クリーンでモダン。情報の優先度がタイポグラフィと色で明確

## レイアウト

### ページ全体

| 要素 | 仕様 |
|------|------|
| 背景色 | ごく薄いグレー（例: `#F5F5F5`） |
| コンテンツ | 縦スクロールのカードリスト |
| カード間隔 | 一定の縦マージン（目安 12〜16px） |

### カード構造

```
┌─────────────────────────────────────┬──────────┐
│  左セクション（約 75%）              │ 右（25%） │
│  ・割引額（最大）                    │ ・チェック │
│  ・カテゴリ                          │ ・適用範囲 │
│  ・クーポン名                        │           │
│  ・利用条件                          │           │
│  ・有効期限                          │           │
└─────────────────────────────────────┴──────────┘
```

| 要素 | 仕様 |
|------|------|
| カード背景 | 白 `#FFFFFF` |
| 角丸 | 8〜12px |
| 影 | 軽いドロップシャドウ（浮遊感） |
| 区切り | 左・右の間に細い縦線（切り取り線のイメージ） |

## 左セクション（メイン情報）

上から下へ、視覚的優先度の高い順に配置。

### 1. 割引額（ヘッドライン）

- **例:** `70% 割引` / `30% 割引`
- **スタイル:** 大きめ・太字・オレンジ（アクセントカラー）
- **役割:** 一覧スキャン時の最重要要素

### 2. カテゴリラベル

- **例:** `配達`
- **スタイル:** 小さめ・太字・黒
- **役割:** クーポンの適用対象（配達／店舗受取など）の即時識別

### 3. クーポン名

- **例:**
  - `[4回目の注文]ウェルカムクーポンセット 70%`
  - `[初回注文限定]ウェルカムクーポンセット 70%`
- **スタイル:** 中サイズ・太字・黒
- **役割:** キャンペーン名・対象ユーザー条件の説明

### 4. 利用条件

- **例:** `1,200円以上ご注文いただいた場合 (2,000円まで)`
- **スタイル:** 小さめ・通常ウェイト・黒
- **役割:** 最低注文額・割引上限などの制約

### 5. 有効期限

- **例:** `2024/07/28 まで使用可能`
- **スタイル:** 小さめ・通常ウェイト・グレー
- **役割:** 期限切れ判断。補助情報として弱めのコントラスト

## 右セクション（スタブ）

| 要素 | 仕様 |
|------|------|
| 配置 | 縦方向中央寄せ |
| アイコン | 小さなグレーのチェックマーク（上部） |
| テキスト | **例:** `全店舗 使用可能` |
| テキスト色 | ミッドグレー |
| 役割 | 利用可否・適用店舗範囲のステータス表示 |

## カラーパレット

| 用途 | 色 |
|------|-----|
| アクセント（割引額） | オレンジ |
| 主要テキスト | 黒 / ダークグレー |
| 補助テキスト（期限・スタブ） | ミッドグレー |
| カード面 | `#FFFFFF` |
| ページ背景 | `#F5F5F5` 前後 |

## タイポグラフィ

- **フォント:** クリーンなサンセリフ
- **階層の作り方:**
  - **サイズ:** 割引額 > クーポン名 > 条件・カテゴリ > 期限
  - **ウェイト:** 見出し系は bold、詳細は regular

## スペーシング・整列

- カード内パディングは十分に取る（窮屈にしない）
- 左セクション: テキスト左揃え
- 右セクション: アイコン・文言を中央揃え
- カード間の縦リズムを一定に保つ

## 実装時のコンポーネント分割案

```
CouponListPage
└── CouponCard
    ├── CouponCardMain（左 75%）
    │   ├── DiscountHeadline
    │   ├── CategoryLabel
    │   ├── CouponTitle
    │   ├── UsageConditions
    │   └── ExpiryDate
    └── CouponCardStub（右 25%）
        ├── StatusIcon
        └── ScopeText
```

## バリエーション・拡張のヒント

| 状態 | 想定される表現 |
|------|----------------|
| 使用済み | 全体を desaturate、右スタブを「使用済み」に変更 |
| 期限切れ | 割引額の色をグレー化、タップ不可 |
| 店舗限定 | 右スタブを `全店舗` → `対象店舗のみ` 等に差し替え |
| 選択モード | 右スタブをラジオ／チェックボックスに置換 |

## 参考メモ

- チケット型 UI は「割引の価値」を視覚的に強調しつつ、条件・期限を同カード内で完結させるのに向いている
- オレンジの割引額＋白カード＋薄グレー背景は、食品・デリバリー系でよく使われる安心感のある組み合わせ
- 右スタブは装飾だけでなく、一覧上でのステータス・適用範囲のスキャン用スペースとして機能している
