## スマホでの開き方

1. このページをSafari/Chromeで開く
2. 上のファイル名をタップ
3. 「Download / ダウンロード」→「ファイルに保存」またはDriveにアップロード

Googleドキュメントにしたい場合は、`.docx` をDriveにアップロード →「アプリで開く」→「Googleドキュメント」
