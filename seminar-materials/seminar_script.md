# 0. オープニング（約2分）

みなさん、今日のテーマはこれです。

**老後対策として、主婦やパートのママが、働き方でできること。**

老後対策には、貯金、節約、保険、資産運用など、ほかにもいろいろあります。  
今日は、それを全部否定する話ではありません。ほかの対策も、必要ならもちろんやります。

ただ、今日は一つだけ、いちばん大きな前提を置きます。

**人生で、生涯収入を増やすことが、もっとも確実な老後対策になりやすい。  
いま働けて、これからも働けそうな人にとっては、働くことがいちばん結果につながりやすい。**

だから今日は、商品の話をしません。  
「どう働くか」の話をします。

もう一つ、先にお断りします。  
いま、ご自身の健康の問題や、親の介護などで、働く量を増やせない方もいると思います。  
そういう方は例外として聴いてください。無理に増やせ、という話ではありません。  
ただ、この会場には基本的に、すでに働いていて、これからも働けそうな方が多い前提で進めます。

# 1. いま、何が起きているか（約2分）【短縮では軽く】

まず、時代の話をします。

いまは、物価が上がっています。  
それに合わせて、給与や時給も動いてきています。  
全国的にも最低賃金が上がっています。  
おまけに私の実感ですが、東京では時給が上がりはじめています。

つまり今は、こういう局面です。

**物価も上がる。最低賃金も上がる。時給も動きやすい。**

そんなときに、「働き方だけ昔のまま」だと、同じ時間で得られるゆとりも、将来の生涯収入も、相対的に目減りしやすいです。

だから今日は、なんとなく働く時間を増やすのではなく、  
**これから先も続けられる働き方の立ち位置**を決めよう、という話です。

# 2. 50代だからこその意味（約2分）【短縮では1文】

もう一つ、世代の話をします。脅しではなく、共有です。

一度いまの仕事を離れたあと、同じような条件の仕事がすぐ見つかるかは、人によります。  
数年後には年齢も上がります。

だから今日は、転職前提の話ではなく、  
**いまの働き方を、できるだけ長く続けられる形に整える話**をします。  
ここ数年でルールも変わるので、その先も使える方針を、今決めておきましょう。

今日いちばん持って帰ってほしい結論は、これです。

**自分の社会保険の考え方をはっきりさせて、それに従って行動する。**

正しい年収の暗記会ではありません。  
「私はどっち側で働くか」を決める会です。

# 4. 働く時間を増やすと、何が起きるのか（約3分）

みなさんが最初に思うことは、だいたいこれです。

「手取りを増やしたい。  
そのために、もう少し働く時間を増やしたい。  
時間が増えれば、給料が増えるはずだ。」

これはとても自然です。  
欲しがっている本体は、働く時間そのものではなく、**給料を増やすこと**です。時間はその手段です。

ただ、給料を増やそうとして働く時間を少し増やすと、社会保険の世界では、大きく分けて3つのどこかに行き着きます。

1. **配偶者の扶養の中にいる**  
2. **自分の勤務先の社会保険に入る**  
3. **どちらでもないところに落ちる**

この3番目がいちばんつらいです。  
なぜなら、配偶者の扶養からも外れ、自分の会社の社会保険にも入れず、  
自分で国民健康保険と国民年金を払う側になりやすいからです。

今日は、この3つの絵を頭に入れてください。

- 緑：配偶者の扶養の中  
- 青：勤務先の社会保険に入る  
- 赤：どちらでもないつらい帯  

講師メモ：図があればここで出す。なければ手で「左・右・間」を示す。

# 5. 言葉のイメージだけ先にそろえる（約2分）【短縮では各1文】

細かい用語は最小限にします。イメージだけ持てれば十分です。

## 5-1. 配偶者の扶養
ざっくり言うと、「配偶者の会社の健康保険に、家族として入っている状態」です。  
中でいるには、自分の見込み収入が大きくなりすぎないことが大切で、よく聞く目安がいわゆる **年収130万円** です。暗記必須ではありません。

## 5-2. 勤務先の社会保険
ざっくり言うと、「自分のパート先で、健康保険と厚生年金に入る状態」です。  
負担は増えますが、自分の名義の土台ができ、長く働く安心につながりやすいです。

## 5-3. どちらでもないつらい帯
扶養からは外れたのに、勤務先の社会保険にも入れない。  
今日いちばん避けたいのが、ここです。

# 6. 会社の人数で、見え方がちょっと違う（約4分）

ここが今日の山場です。  
**2026年10月以降の前提**で、おおまかに話します。

勤務先の社会保険に入る道は、ざっくり2つあります。

## 道その1：がっつり働く道（おおむね週30時間前後）

正社員のおよそ4分の3くらい働くと、会社の社会保険に入りやすい。  
イメージとしては **週30時間前後** です。  
この道は、会社が小さくても大きくても、関係しやすいです。

## 道その2：週20時間の道（一定以上の人数の会社）

会社がある程度の人数になると、もっと短い時間でも社会保険に入れる道があります。  
ここでの境目のイメージが **週20時間** です。

**ここで言う時間は、基本的に「契約やシフトの前提として、週に何時間働くことになっているか」です。  
たまたま残業で超えた、とは限りません。**

いまの段階で覚えたいのは、これです。

- **会社がおおむね51人以上**  
  → 週20時間以上なら、勤務先の社会保険に入りやすい
- **会社がおおむね51人未満**  
  → この「週20時間の道」は、まだ来ていないイメージ  
  → 入りやすいのは、だいたい週30時間前後のがっつり道

「小さめの会社」は別カテゴリーではありません。  
**いまはまだ、週20時間の特別な道が来ていない会社**、くらいに思ってください。  
なお、51人未満でも社会保険が一切ないわけではなく、がっつり道（週30時間前後）はあります。

講師メモ：  
「51人」は店の頭数とは限らない（厚生年金の被保険者数など）。会場では深入りせず、確認は会社へ。

講師メモ（本番前）：  
賃金要件が外れる施行月と、企業規模の次のしきい値だけ、公式（厚労省・日本年金機構）で最終確認する。日付がずれていたら、導入の「10月は目の前」を調整する。

# 7. じゃあ、なぜ「間」がつらいのか（約4分）

ここがいちばん大事です。

## 7-1. 51人未満の会社の場合

たとえば、週22時間、25時間くらい働いたとします。  
いまの時給水準で、普通にその時間帯で働くと、**年収130万円はだいたい超えます**。

するとどうなるか。

- 配偶者の扶養からは外れやすい  
- でも会社は51人未満なので、週20時間の道はまだ使えない  
- 週30時間前後までいっていないので、がっつり道にも届いていない  

つまり、

**扶養にもいられず、勤務先の社会保険にも入れない。**

これがつらい帯です。

だから、普通の感覚ならこうなります。

「だったら、どちらかに寄せよう。」

- 手前：扶養の中に収まるまで抑える  
- 向こう：いっそ週30時間前後まで働いて、勤務先の社会保険に入る  

中途半端がいちばんつらい。

## 7-2. 51人以上の会社の場合

こちらは、10月以降もっとシンプルです。  
境目のイメージは **週20時間（所定）** です。

- 週20時間以上：勤務先の社会保険に入りやすい  
- 週20時間未満：入りにくい  

ただし注意があります。  
時給が高いと、週20時間未満でも年収130万円を超えることがあります。  
すると、「会社の社会保険には入っていないのに、扶養だけ外れる」ことが起き得ます。  
だから①を選ぶ人は、時間だけでなく、年収130万円も必ず見ます。

# 8. 会社側の事情（約2分）【短縮では1文】

働く側だけが慎重なのではありません。  
パートの人が勤務先の社会保険に入ると、会社にも追加の社会保険料がかかります。  
入口付近では、会社も慎重になりやすいです。

ただ、会社が「社会保険を避けるためだけに短い時間の人を集める」方針だと、現場は続きにくくなりやすい、ということは言えます。

分かりやすい対比として、

- A社：社保回避だけで、短い時間の人を集める  
- B社：しっかり働いて稼ぎたい人を集める  

どちらが中長期で続きやすいか、イメージしてみてください。

物価も最低賃金も上がり、人手不足も続く時代では、  
「社会保険のコストを避けること」だけを採用の中心に置く会社は、人を集めにくくなりやすいです。

**※①を選ぶみなさんを責めているのではありません。**  
事情があって扶養の範囲内で働くのは、正しい選択の一つです。  
今日決めたいのは、会社論ではなく、**自分がどの立ち位置で働くか**です。

# 9. 自分の考え方は、この3択（約6分）【短縮では小話1本まで】

老後のために生涯収入を増やしたい。  
その途中で立ち位置を間違えないための3択です。  
どれが偉い、ではありません。

## 選択肢①  
当面は、配偶者の扶養の範囲内で働く

向いている人：

- いまは時間を大きく増やせない  
- あるいは、勤務先の条件的にすぐ社会保険に入れない  
- だから今は守る局面だ、と言える人

やることはシンプルです。

**見込み年収が、いわゆる130万円を超えないように働く。**  
時給が高いほど、少ない時間でも超えるので注意します。  
会社が51人以上なら、加えて週20時間未満（所定）も見ます。  
副業がある人は、給与だけでなく合計で見ます。

大事なのは、「ずっとこのまま」ではなく、見直し時期を持つことです。

### 小話：美紀さん（54）【短縮でも残してよい】

美紀さんは、手取りを増やしたくて、働く時間を少し増やしたいと思っていました。  
でも確認したら、少し増やすと扶養から外れるのに、勤務先の社会保険には入れそうになかった。  

そこで美紀さんは決めました。  
**「今は扶養の中で守る。入れる条件が見えてから増やす。」**

---

## 選択肢②  
勤務先と相談して、社会保険の対象者として働く

向いている人：

- これから数年、長く働きたい  
- 自分の社会保険の土台を持ちたい  
- 制度のたびに、その場しのぎで時間を変えるのをやめたい人

やることは、会社規模で分かれます。

- **51人未満の会社**  
  → おおよそ週30時間以上など、がっつり道で入れるところまで働く
- **51人以上の会社**  
  → 週20時間以上（所定）で、対象者として働く

②を選ぶということは、配偶者の扶養から外れる覚悟でもあります。  
手取りが一気に増えなくても、長く働いて生涯収入を積み上げるための覚悟です。

### 小話：智子さん（52）【短縮ではカット可】

智子さんはこれまで、「130万円を超えない」ことが口ぐせでした。  
でもルールは広がっていくし、毎回転職で合わせる前提にもしたくない。  

智子さんは店長に確認して決めました。  
**「自分は勤務先の社会保険に入る側に行く。その条件に合わせてシフトを組む。」**

---

## 選択肢③  
どちらからも外れて、見合うところまで本気で稼ぐ

向いている人：

- 仕事やスキルがあり、収入を本気で増やせる  
- 少しだけ増やすと、赤ゾーンに入りやすい  
- だから中途半端はやめて、負担を織り込んで大きく増やす覚悟がある人

やってはいけないのは、  
「気がついたら扶養から外れていた」です。  
外れるなら、先に決めて、見合う収入まで増やす。

### 小話：京子さん（55）【短縮ではカット可】

京子さんは在宅の仕事が増えてきました。  
扶養に収めようとすると仕事が育たない。  
少し増やすと、赤ゾーンに入りやすい。  

京子さんは決めました。  
**「外れるなら、少しだけはやめる。見合うところまで本気で増やす。」**

# よくある質問（短答）

**Q. 私は扶養のままがいい？**  
A. ①ならそれでよい。なんとなくではなく、130万と時間を意識して。見直し時期も決める。

**Q. 損するのが怖い。**  
A. 怖いのは損そのものより、間のつらい帯に居続けること。手前か向こうかに寄せる。

**Q. 副業は？**  
A. 扶養を見るなら合計収入。給与を抑えて副業で増やすと、外れることがある。

**Q. 資産運用は？**  
A. 大事。でも今日の主題は働き方。運用は別の回で。

**Q. 正確な人数の数え方が分からない。**  
A. 自分で完璧に数えなくてよい。会社に「私の職場は週20時間の世界ですか、週30時間の世界ですか」と聞く。
