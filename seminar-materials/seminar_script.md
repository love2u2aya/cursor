## 0. はじめに（1分）
**スライド：** 表紙 → 「今日の4つのポイント」

「今日は、制度の細かい話を一気に覚える会ではありません。  
聞いたあと、ご自身の働き方を決めるときの“見方”が残れば十分です。  

結論から言うと、ルール変更は多いんですが、見る柱は少ないです。  
今日、覚えて帰っていただきたいのは次の4つです。」

1. **給与収入で社保の土台を決める**（10月以降は週20時間が焦点）
2. **複数の収入源でリスクヘッジ**
3. **副業も検討**（扶養内は合計年収で見る）
4. **目的は税・社保を安くすることではなく、長く働ける自分であること**

「特に最後がいちばん大事です。」

## 1. 働き損って何？（3分）
**スライド：** ①セクション → 働き損ゾーン早見図 → 手取り推移

「よく聞きますよね。『働き損』。  
稼いだのに、手取りが思ったより増えないゾーンがある、という話です。」

（早見図を出す）

「色で言うと、ざっくり3つ。  
・**青**：勤務先の社会保険に乗る  
・**緑**：配偶者の扶養の中  
・**赤**：国保＋国民年金。ここがいちばんキツい帯です。」

（手取りグラフ）

「年収を上げても、手取りの伸びが鈍るところがあります。  
だから『働くな』ではなくて、**どこで働くかを選ぶ**、というのが今日のテーマです。」

## 2. 実質の損と、ご主人との比較（4分）
**スライド：** 実質損v2拡大 → 500万/700万のどちらか内訳 → 夫＋100万グラフ

「ここに印象操作もあるので、定義をはっきりさせます。  
今日の“実質損”は、扶養内でいちばん手取りがいい付近（だいたい129万）と比べて、どれだけ損な感じがするか、です。」

（v2拡大）

「制度上は、130万の壁を越えたあと、およそ150〜160万あたりで“戻る”イメージもあります。  
でも気持ちの話で言うと、多くの方が『実質戻った』と感じるのはもっと先だと思っています。  

私の実感ラインは、こんな感じです。  
・106万付近 → **176万**くらい  
・130万付近 → **200万**くらい  
年にプラス70万、月にだいたいプラス6万。『実質倍くらい』くらい稼がないと、損した感じは抜けにくい。」

（損の内訳：手元の世帯に近い方を1枚だけ）

「損の中身は一種類じゃありません。  
税金、社会保険、配偶者特別控除の縮小などが重なります。  
世帯の夫の年収が500万と700万でも、妻側の見え方は少し変わります。」

（夫＋100万）

「ここが、今日いちばん言いたいところです。  
『働き損だから、私は稼げない』と感じやすいんですが、  
**ご主人も損しながら稼いでいる**んです。会社員は当たり前にそうです。  

だから『損するのが怖い』だけでは、世帯の選択を誤ります。  
ただし『稼げるだけ稼ごう』も危険です。  
**壁の手前か、向こう側を選ぶ**。中途半端がいちばんつらい。」

## 3. 社会保険マップ（4分）★図解の山場
**スライド：** 時系列 → 51人以上 9月vs10月 → 範囲拡大2027 →（時間あれば10月比較）

「次に、2026年からの社会保険の地図です。  
細かい数字より、地図の形を見てください。」

（時系列）

「2026年10月と、2027年10月で、対象になる会社の範囲が広がっていきます。」

（51人以上・before/after）★

「まず、51人以上の会社。  
〜9月までは、賃金要件なども絡んで複雑でした。  
**10月以降は、賃金要件が撤廃され、週20時間が主軸**になります。  
週20時間以上なら、勤務先の社保に乗るイメージです。」

「50人以下はどうか。当面は、短時間ルールの対象外で、おおよそ週30時間（3/4）から。  
地図が会社の規模で違う、というのが大事です。」

（scope_expand_2027）★

「2027年10月からは、**36人以上**にも同じ週20時間の地図が広がります。  
35人以下は当面対象外。  
ポイントは、『ルールの形がガラッと変わる』のではなく、  
**地図の形は同じで、当てはまる会社の範囲だけ広がる**、ということです。」

「極論を言うと、  
勤務先社保に乗れないなら、扶養内が合理的なことも多い。  
外れるなら、国保で中途半端はキツい。めちゃ稼ぐか、本気で事業をやるなら法人、という選択になります。」

## 4. 4ポイントに戻す／締め（3分）
**スライド：** 「まとめ」スライド

「最後に、最初の4つに戻します。」

1. **給与で社保の土台を決める**  
   「パートなら、週何時間・どの規模の会社かが先。年収だけ見て決めない。」
2. **複数の収入源**  
   「給与に寄せすぎない。でも扶養を気にするなら合計年収。」
3. **副業も検討**  
   「給与だけで壁を越えにいくより、家計と生活設計に合う形を。」
4. **長く働ける自分**  
   「税や社保を安くすることがゴールではない。  
   物価高の中、年収700万＋お子さん2人、という世帯でも楽ではありません。  
   妻の方が長生きしやすく、年金が薄い世代でもある。  
   生涯収入と年金を減らさないために働く。」

「ルールは変わる。でも見る柱は少数。  
損を恐れて止まらない。ご主人も損しながら稼いでいる。  
ただし中途半端は選ばない。手前か、向こう側。  
今日は、ここまで持って帰ってください。ありがとうございました。」

## よくある質問（予備・各30秒〜1分）

**Q. 私は扶養のままがいい？**  
「勤務先社保に乗れない働き方なら、扶養内が合理的なことも多いです。会社の人数と週の時間を先に見てください。」

**Q. いくらまでなら大丈夫？**  
「『大丈夫』は目的次第です。壁の手前で留めるのか、向こう側までいくのか。今日の実感ライン（176／200）は“気持ちの回復”、制度の回復点はもう少し手前、という整理です。」

**Q. 副業したら？**  
「扶養判定は合計年収で見ることが多いです。給与を抑えて副業で増やすと、結果として外れることがあります。」

**Q. 資産運用は？**  
「大事ですが、今日の主題は働き方と社保・扶養の地図です。運用は別の回で。」
